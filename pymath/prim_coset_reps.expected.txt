Primitive coset representatives and the index of Gamma_0(12)

== 1. The running example: N, psi(N), phi(N) ==

  Fix N = 12 = 2^2 * 3 and write psi(N) = N prod_{p | N} (1 + 1/p) for the
  index of Gamma_0(N), and phi(N) = #(Z/N)^* for Euler's totient. At N = 12
  the product is 12 * (1 + 1/2) * (1 + 1/3) = 24, while phi(12) = 4. The
  divisor-sum form of psi is the sum of N/d over the squarefree divisors d of
  N.
    N = 12 = 2^2 * 3,  prime factors = [2, 3]
    psi(N) = 24,  phi(N) = 4
    squarefree divisors = [1, 2, 3, 6]  ->  sum N/d = 24
    ok   psi(N) = N prod (1 + 1/p) = sum over squarefree d | N of N/d
    ok   psi is multiplicative on coprime arguments

  On a prime power psi and phi are complementary: psi(p^k) = p^k + p^(k-1)
  counts the k-digit residues together with the leading k-1-digit ones,
  phi(p^k) = p^k - p^(k-1) counts the units, and psi(p^k) + phi(p^k) = 2 p^k.
  Section 8's fibre count produces psi(p^k) out of phi on the same prime
  power, which is why the two functions meet here.

== 2. The projective line: unimodular pairs modulo units ==

  A pair (a, c) in (Z/N)^2 is unimodular when it generates the unit ideal,
  i.e. there exist x, y with x a + y c = 1. Over Z/N that is the same as
  gcd(a, c, N) = 1. The unit group (Z/N)^* acts on unimodular pairs by
  scaling, freely: if u a = a and u c = c for a unimodular pair then u = 1.
  The projective line P^1(Z/N) is the set of orbits.
    unimodular pairs: 96 = N^2 prod (1 - p^-2);  units: [1, 5, 7, 11] (phi = 4)
    orbit sizes: [4];  lines: 24 = psi(N) = 24
      0:1    1:0    1:1    1:2    1:3    1:4    1:5    1:6
      1:7    1:8    1:9   1:10   1:11    2:1    2:3    2:5
      3:1    3:2    3:4    3:7    4:1    4:3    4:5    6:1
    ok   unimodular iff gcd(a, c, N) = 1 (Bezout by brute force)
    ok   the unit action is free: every orbit has exactly phi(N) elements
    ok   #P^1(Z/N) = #unimodular pairs / phi(N) = psi(N)

  The same count is the index of the Borel subgroup B(Z/N) of upper triangular
  matrices in SL_2(Z/N): a matrix is sent to the line of its first column, and
  two matrices have first columns in the same unit orbit exactly when they
  differ by an element of B. So the right cosets of B are the lines,
  #(SL_2(Z/N) / B(Z/N)) = #P^1(Z/N).
    #SL_2(Z/12) = 1152 = N^3 prod (1 - p^-2);  #B(Z/12) = 48 = N phi(N) = 48;  fibres = 24, each of size [48]
    ok   the right cosets gB are the lines: every first-column fibre has size #B = N phi(N)
    ok   #(SL_2(Z/N) / B(Z/N)) = #P^1(Z/N) = psi(N)

== 3. Smith normal form: primitive = diag(1, N) = row cyclic ==

  For an integer matrix M of determinant N, Smith normal form is U M V =
  diag(d1, d2) with U, V in SL_2(Z), d1 | d2. The first invariant factor d1 is
  the gcd of the four entries of M, and d1 d2 = N; the matrix is primitive
  when d1 = 1, i.e. when its Smith form is diag(1, N). The row lattice L =
  rows(M) gives Z^2 / L = Z/d1 x Z/d2, so primitive is also exactly "row
  cyclic": the quotient is a cyclic group of order N. (A non-primitive
  determinant-N matrix can exist only when some p^2 divides N, since d1 | d2
  forces d1^2 | N.)

== 4. Hermite normal form: the left action's canonical form ==

  Row operations are the left action M -> U M with U in SL_2(Z). They preserve
  the row lattice, and the Hermite normal form is the unique representative of
  that orbit which is upper triangular, [[a, b], [0, d]] with a, d > 0 and 0
  <= b < d: the Euclidean steps make the (1,0) entry zero, then reduce b
  modulo d. The point to keep apart from Smith form is which gcd shows up: the
  diagonal (a, d) of the Hermite form is *not* the Smith diagonal, but the
  first invariant factor of the Hermite form is gcd(a, b, d) = gcd(a, gcd(b,
  d)), so the triples of section 8 are exactly the Hermite forms that are
  primitive.
    [[2, 1], [0, 6]]:  U = [[1, 0], [0, 1]],  H = U M = [[2, 1], [0, 6]],  det U = 1,  Smith diagonal = (1, 12)
    ok   H = U M is upper triangular with a, d > 0, 0 <= b < d, and (gcd(a, b, d) = 1) iff M is primitive, for [[2, 1], [0, 6]]
    a generic primitive matrix:  U = [[0, 1], [-1, 13]],  H = U M = [[1, 1], [0, 12]],  det U = 1,  Smith diagonal = (1, 12)
    ok   H = U M is upper triangular with a, d > 0, 0 <= b < d, and (gcd(a, b, d) = 1) iff M is primitive, for a generic primitive matrix
    diag(2, 6):  U = [[1, 0], [0, 1]],  H = U M = [[2, 0], [0, 6]],  det U = 1,  Smith diagonal = (2, 6)
    ok   H = U M is upper triangular with a, d > 0, 0 <= b < d, and (gcd(a, b, d) = 1) iff M is primitive, for diag(2, 6)
    ok   Hermite diagonal (2, 6) differs from the Smith diagonal (1, 12) at [[2, 1], [0, 6]]

  The left action preserves the row lattice and the Hermite form is a complete
  invariant of it: M and U M have the same Hermite form for every U. So the
  Hermite forms of determinant-N matrices are a transversal of the left
  action, one representative per row lattice of index N; those whose quotient
  Z^2/L is cyclic (equivalently, that are primitive) are the triples below.

== 5. Left vs right action, the double coset, and Gamma_0(N) ==

  The two actions do different things. Left multiplication U M mixes the rows,
  so it fixes the row lattice; right multiplication M V mixes the columns, so
  it fixes the column lattice but moves the row lattice in general. Smith form
  uses both at once, which is why it can put a primitive M into diag(1, N) for
  any M in the set: the determinant-N primitive matrices are exactly the
  double coset SL_2(Z) diag(1, N) SL_2(Z).
    M = [[13, 1], [1, 1]],  V = [[1, 1], [0, 1]],  M V = [[13, 14], [1, 2]]
    ok   the left action preserves the row lattice for every U in the sample
    ok   the right action preserves the column lattice for every V in the sample
    a left witness U = [[1, 1], [0, 1]] moves the column lattice; a right witness V = [[1, 1], [0, 1]] moves the row lattice
    ok   left action can change the column lattice, right action can change the row lattice

  For a primitive M the Smith decomposition U M V = diag(1, N) reads M =
  U^{-1} diag(1, N) V^{-1}, the double coset membership in coordinates; a
  non-primitive M has d1 > 1, and d1 is unchanged by either unimodular action,
  so it is outside the double coset.
    ok   every triple is U diag(1, N) V with U, V in SL_2(Z) (the double coset)
    ok   a non-primitive determinant-N matrix is not in the double coset (its d1 is invariant)

  The group Gamma_0(N) reappears as the stabiliser of the matrix diag(N, 1).
  Right multiplication moves the row lattice, L -> L gamma, so gamma
  stabilises diag(N, 1) when L gamma = L, for L = N Z x Z the row lattice of
  diag(N, 1). That happens exactly when the second row (c, d) of gamma lies in
  L, i.e. N | c: the defining congruence of Gamma_0(N). Equivalently,
  conjugating gamma = [[a, b], [c, d]] by diag(N, 1) gives [[a, N b], [c/N,
  d]]. The factor diag(N, 1)^-1 is not an integer matrix, and that is fine:
  the conjugation is a test over Q, and the test is whether the product is
  integral, which happens iff N | c.
    diag(N,1) gamma diag(N,1)^-1 = [[a, N b], [c/N, d]] on samples:
        gamma = [[1, 0], [0, 1]], c =   0:  conjugate = [[1, 0], [0, 1]],  integral = True,  L gamma = L = True
        gamma = [[1, 1], [0, 1]], c =   0:  conjugate = [[1, 12], [0, 1]],  integral = True,  L gamma = L = True
        gamma = [[2, 3], [1, 2]], c =   1:  conjugate = [[2, 36], [1/12, 2]],  integral = False,  L gamma = L = False
        gamma = [[5, 2], [2, 1]], c =   2:  conjugate = [[5, 24], [1/6, 1]],  integral = False,  L gamma = L = False
        gamma = [[2, 1], [3, 2]], c =   3:  conjugate = [[2, 12], [1/4, 2]],  integral = False,  L gamma = L = False
    over the 116 matrices of SL_2(Z) with entries in [-3, 3], 14 lie in Gamma_0(N) and stabilise L
    ok   diag(N,1) gamma diag(N,1)^-1 is integral iff N | gamma[1][0] iff gamma stabilises the row lattice L = N Z x Z

== 6. The fibre count: a totient count in the second coordinate ==

  Reindex the triples by the first and third entries. For each (a, d) with ad
  = N the admissible b are exactly those below d that are coprime to g =
  gcd(a, d), because gcd(a, gcd(b, d)) = gcd(g, b). Residues coprime to g are
  g-periodic, so a block of m periods contains m phi(g) of them and #{b < d :
  gcd(g, b) = 1} = (d/g) phi(g). That value h(a, d) is the fibre count, and
  summing it over the divisors-antidiagonal gives G(N) = psi(N).
    (a,d)=( 1,12) g= 1  #{b<d: gcd(g,b)=1}= 12  (d/g)phi(g)= 12    (a,d)=( 2, 6) g= 2  #{b<d: gcd(g,b)=1}=  3  (d/g)phi(g)=  3
    (a,d)=( 3, 4) g= 1  #{b<d: gcd(g,b)=1}=  4  (d/g)phi(g)=  4    (a,d)=( 4, 3) g= 1  #{b<d: gcd(g,b)=1}=  3  (d/g)phi(g)=  3
    (a,d)=( 6, 2) g= 2  #{b<d: gcd(g,b)=1}=  1  (d/g)phi(g)=  1    (a,d)=(12, 1) g= 1  #{b<d: gcd(g,b)=1}=  1  (d/g)phi(g)=  1
    sum over ad = 12: 24
    ok   gcd(a, gcd(b, d)) = gcd(gcd(a, d), b) for every triple
    ok   the fibre count is the totient count: #{b < d : gcd(g,b) = 1} = (d/g) phi(g)
    ok   the block law #{b < g m : gcd(g, b) = 1} = m phi(g)
    ok   G(12) = sum over ad = N of h(a, d) = psi(12)

  The fibre value is multiplicative in the pair, so G is multiplicative and it
  is enough to check it on prime powers, where h(p^(k-j), p^j) = phi(p^j) for
  1 <= j <= k-1 and the two end terms contribute 1 and p^k, giving G(p^k) =
  p^k + p^(k-1). Two multiplicative functions agreeing on prime powers are
  equal, so G = Psi = mu^2 * id and the second headline follows.
    ok   G is multiplicative on coprime arguments
    ok   G(p^k) = p^k + p^(k-1), agreeing with psi
    ok   Psi = mu^2 * id on the squarefree divisor sum: G(N) = sum over squarefree d | N of N/d

== 7. What the formalization does with this ==

  The formalization records the index set as the triples
  (ModularCurve.primCosetReps), reindexes them by the divisors-antidiagonal
  (card_primCosetReps_eq_sum), and counts each fibre by the totient block fact
  (card_filter_coprime_range_mul) to get dedekindPsiFibre and card_fibre.
  Multiplicativity of the summand (h_mul, isMultiplicative_G) reduces the
  count to prime powers (h_prime_pow, G_prime_pow), and G_eq_Psi, Psi_apply
  identify the result with psi. The double-coset statement behind section 8.1
  is exists_eq_mul_diagonal_mul_of_gcd_eq_one, which exhibits the two outer
  SL_2(Z) factors for a primitive matrix; the section-5 route to the same
  number is card_quotient_borel and card_projectiveLine_zmod.

  Concretely, the matrices in this demo are the ones the q-expansion layer
  enumerates: the triples (a, b, d) index the cosets of Gamma_0(N), and the
  row lattice of [[a, b], [0, d]] modulo N is a cyclic subgroup of order N in
  (Z/N)^2 -- a point of the projective line of section 2. The
  reduced-row-lattice map makes that explicit.
