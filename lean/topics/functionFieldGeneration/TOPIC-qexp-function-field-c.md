work-order cut for
`ModularCurve.qExpFunctionFieldC_rat_gamma0_eq_modularFunctionFieldFull`. The cone

**Goal** (the pin wrapper's statement, verbatim; pin `aa2d8b3`):

```lean
theorem ModularCurve.qExpFunctionFieldC_rat_gamma0_eq_modularFunctionFieldFull
    (M : ℕ) [NeZero M] :
    qExpFunctionFieldC ℚ (Gamma0 M) = modularFunctionFieldFull M
```

The field generated by ratios of integral `q`-expansions at `Γ₀(M)` is the full
divisor field `ℚ(j(q^d) : d ∣ M)`. **Its own proof is 128 lines** — a relative-degree
squeeze (§4 Set D). The 34-node cone is the cost.

## 6. Risks, and the stop-early protocol

1. **`StarBank` (new analysis).** Hasse-polynomial descent over `jqModC` plus eta /
   `qTwist` rewriting. The only place a route can be wrong; scout before dispatch
   (playbook §2.6). Stop-early: if the descent does not reproduce in one round,
   re-scope rather than push.
2. **Heartbeat walls.** The `S_` files set `maxHeartbeats 6400000` and
   `synthInstance.maxHeartbeats 1600000`; `StarBank` and `JOneES` are the likely
   heavy elaborations. If instance search bites, record it in
   [instance-friction.md](../../instance-friction.md) rather than raising budgets.
3. **`C`-layer drift.** ~15 API renames (`jq` → `jqModC`, `modularFunctionFieldFull`
   → `…FullC`, `ModularPolynomialData` lemmas). Per playbook §7 this is the recurring
   real cost; keep the list in the log, and do not re-cut the cone over it.
4. **The socket route may be unnecessary.** Budget assumes it is written. If the
   ported `exists_phiIrreducible` route can back the `C` layer, Set C shrinks by
   ~2,700 raw; check at the end of Set A, before writing any of it.
