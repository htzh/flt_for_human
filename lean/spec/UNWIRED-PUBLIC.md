# The unwired public surface

Public declarations of the port that the statement checker does not cover,
because their module is not listed in `spec/check_flt_statements.py`'s
`PORT_FILES`.  They are built and importable — this register is so that a
future proof can *find* them, and so that their statements are one step from
being diffed.

Generated by `tools/deps/unwired_register.py`; run it with `--check` to see
whether the tree has drifted.  Nothing here is verified against the pin: the
`pin original` column names the declaration (and the file holding it) that
carries the statement to diff when the entry is wired.

`683` public declarations in `24` unlisted modules; `397` of them have a pin counterpart by name and statement.

This is tier 3 only.  Tier 2 — a declaration in a *listed* module that the
checker skips — is `OWN_PROOFS` in the checker itself, each entry carrying its
reason; tier 1 is the checked surface.

**To wire one** (or a whole module): add the module to `PORT_FILES` and the
pin files its declarations come from to `SOURCES` — both appended last — then
run `python3 spec/check_flt_statements.py` and reconcile the `identical` delta
against the new public surface.  A port name that is not the pin's needs a
`RENAMES` entry so the statement is still diffed rather than exempted.  Then
delete the entry here.

Names are the port's own (mathlib style); the pin original is recovered from
a `-- pin: <name> (<file>:<line>)` comment above a transcribed declaration,
falling back to the checker's own name/statement lookup for declarations that
still carry the pin's name.

**To use one**: read its `pin original` file for the signature.  The pin clone
is public at `github.com/anthropics/fermats-last-theorem` pinned `aa2d8b3`
(raw URLs stay correct when the content is quoted; `Theorems/` pages carry the
wrappers whose statements the checker diffs).
