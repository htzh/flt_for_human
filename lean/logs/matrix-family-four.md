   descent: a commuting family of `n × n` integer matrices whose ℂ-side common-eigenspace datum is
   `d`-dimensional admits, over **any** characteristic-zero field `K`, a bijective
   `∑ c k • (M k · w k)` for the **transposed** family. Namespaces `TrFrob`/`TrDesc`/`TrFinal` kept

   "private `descent`" was a misread of `port_advise`, corrected here (the priced 63 wired / 1 private
   is what landed).
2. **`Matrix.specialUnitaryGroup_fin_two_eq_diag_mul_rotation_mul_diag`** (114) — every `k ∈ SU(2)` is
   `diag(e^{ia}, e^{-ia}) · rotation(b) · diag(e^{ic}, e^{-ic})`; `namespace Matrix.SU2EulerAux`, no drift.
3. **`Matrix.SpecialLinearGroup.closure_diagonal_unipotent_weyl_eq_top`** (86) — `SL₂(K)` is generated by
   the diagonal, the upper unipotent and the Weyl element; the whole proof is 8 `private` declarations,

## 2. Drift against `v4.34.0`

Rows 2 and 4 are drift-free. Row 3 has the set's only real proof drift, and it is one `convert`
behaviour change: in `v4.34` `convert hmem using 2` between two `Membership.mem` props yields an
`Iff` goal instead of the element equality, so both arms (diagonal/unipotent and Weyl) go through
`set P : SL(2,K) := …` + `have heq : ⟨matrix, _⟩ = P := by refine Subtype.ext …` + `rw [heq]; exact
hmem`. The `set` is load-bearing: writing the four-fold product's coercion directly is rejected
(coercion lifting builds `HMul SL SL Matrix`). Tactic imports `FieldSimp`/`FinCases`/`LinearCombination`
added (the pin got them from `P2M.Util`'s `Mathlib` import).

Row 1 has nine mechanical adaptations, all recorded in the order's §5 register in the module header:
the deprecated `Mathlib.Data.Complex.Basic` → `Mathlib.Basic.Complex.Basic`; five
`omit [IsMulCommutative ↥𝒜] in` (the pin suppressed the linter file-wide, the port omits per
declaration); nine `haveI : …` → `have : …` (the 4.34 `linter.style.haveILetI` suggestion, sound for
Prop-valued instances); `rintro _ ⟨i, rfl⟩ _ ⟨j, rfl⟩` gaining a trailing `_` (`Set.Pairwise` now
carries the `≠` hypothesis); one binder spelled `(Fin d → ↥(TrDesc.AK N ℂ)) ≃ (Fin d → 𝒜)` instead of the
pin's expanded adjoin (the pin's spelling is ill-typed at `implicit` transparency and blocked
`Function.comp_apply`); and one `rw` with an explicit `show … from coe_τ_symm M ℂ (c' j)` for the same
reason. Its import set replaces the pin's `import Mathlib` with 33 named modules.
